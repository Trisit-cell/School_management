# School Management System

A Python-based school management application to manage student records, admissions, and reports.

## Features
- Add, update, and delete student records
- Search records by Roll Number / Name
- View class-wise lists
- File handling / CSV data storage

## Prerequisites
- Python 3.x

## How to Run
1. Clone or download this repository.
2. Open terminal/command prompt in the folder.
3. Run:
   ```bash
   python school_management.py
